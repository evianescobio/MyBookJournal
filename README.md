# 📚 MyBookJournal

*A simple command-line journal application built in C++*

---

## 🧠 About the Project

**MyBookJournal** is a small project I’ve been thinking about for a while now.  
I personally love books, so the idea of creating a program where I can store every book I’ve read came naturally.

The purpose of this program is to **collect, store, and display every book** with its **title** and **author**, and eventually add more features in the future — like saving to a file, editing, or deleting entries.

This is one of my first modular C++ projects, where I learned how to split code into **header files** (`.h`) and **source files** (`.cpp`), and how to structure everything cleanly across folders.

---

## ⚙️ Features

✅ Add a new book with its title and author  
✅ View all books currently saved in the session  
✅ Simple, clean text interface  
✅ Modular design with multiple files and folders  

---

## 🧩 How It Works

1. Run the program.  
2. Choose an option from the menu:
   - **1** → Add a new book (you can include spaces in titles and author names)
   - **2** → View all the books you’ve added
   - **3** → Exit the program

Your list is kept in memory while the program runs (future versions will include saving to file).
